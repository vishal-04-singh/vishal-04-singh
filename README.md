## About

I'm an MCA student specializing in AI & Machine Learning, with hands-on experience building web interfaces, full-stack products, and AI-powered applications. I enjoy turning requirements into clear user flows, responsive interfaces, reusable components, and useful product features.

I'm especially interested in the intersection of **product experience, frontend engineering, and Gen-AI-assisted workflows**—using AI to explore ideas and speed up implementation while reviewing the output for correctness and usability.

- **Frontend:** React, Next.js, TypeScript, Tailwind CSS
- **Product UI:** Responsive layouts, reusable components, accessible UI primitives, interaction design
- **Applied AI:** LLM tool calling, RAG, LangChain, LangGraph, Ollama, Groq
- **Backend:** Node.js, Express, REST APIs, PostgreSQL, MongoDB, Prisma
- **Currently interested in:** UI/UX, product engineering, AI-assisted workflows, and high-ownership internships

## Featured Projects

### [IntelAi — AI Products Marketing Website](https://www.intelaidata.com/)
**Next.js · React · TypeScript · Tailwind CSS · Framer Motion · GSAP · Radix UI**

- Built a responsive marketing website for AI products with server-rendered and statically generated pages.
- Created reusable UI components and integrated accessible interface primitives and theme switching.
- Added motion and scroll interactions while keeping the experience responsive across screen sizes.

### [Noteblock — Collaborative Workspace](https://github.com/vishal-04-singh/Noteblock)
**React · TypeScript · Tailwind CSS · Node.js · PostgreSQL**

- Built an interactive workspace with interface behavior that adapts to Owner, Editor, and Viewer permissions.
- Extended a rich-text editor with code blocks, Markdown export, revision history, and restore actions.
- Implemented loading and error states alongside secure read-only sharing workflows.

### [SkillSwap — Peer-to-Peer Skill Sharing](https://skillswap-five-navy.vercel.app/)
**React · TypeScript · Tailwind CSS · Node.js · MongoDB**

- Developed a multi-page platform with reusable interface components and role-based Student/Faculty experiences.
- Connected the frontend to REST APIs and handled data fetching, loading, validation, and error states.
- Added responsive layouts and page transitions with Framer Motion.

### [LeanAI — AI Context Bundler & Multi-Agent Workbench](https://github.com/vishal-04-singh/LeanAI)
**Tauri · React · TypeScript · Rust · LangGraph**

- Building a desktop-oriented AI workbench concept for gathering project context and coordinating task-focused agents.
- Focused on helping users move between context preparation, model routing, and multi-agent workflows in one application.

### [Multi-Tool ReAct Agent](https://github.com/vishal-04-singh/Multi-Tool-React-Agent)
**Python · LangGraph · LangChain · ChromaDB · Groq · Ollama**

- Built an agent that routes questions to web search, Wikipedia, safe math, and a retrieval-augmented knowledge base.
- Added structured tool argument schemas and execution tracing to make tool use easier to inspect.
